Privacy Policy

Last updated: November 12, 2026

Clipper is a personal application operated by its owner for their own YouTube channel and Instagram account. It has no other users.

YouTube API Services

Clipper uses YouTube API Services. By using Clipper you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data accessed

Clipper requests one Google OAuth scope, https://www.googleapis.com/auth/youtube.upload, and calls only the videos.insert method to upload videos to the owner's channel. It does not read, collect or store data about any other person, and does not access any YouTube data other than what is needed to upload.

How data is used and shared

The OAuth token is used only to upload the owner's clips. No data is sold, shared with or disclosed to third parties.

Storage

The OAuth refresh token is stored only on the owner's private computer in a file readable only by the owner's user account. Generated clips are stored locally and deleted automatically within 7 days after they are posted.

Deletion and revoking access

  • Access can be revoked at any time on the Google security settings page. Revoking access stops all uploads immediately.
  • When access is revoked or the tool is retired, the stored token is deleted within 7 days.
  • Videos already uploaded can be deleted in YouTube Studio.

Clipper's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
